# Trade Row Lab

Structured record of trade/setup observations transcribed from annotated MT5 charts.

- `trade-rows.csv` — one row per observed setup (taken or skipped). Closed vocabulary,
  transcribed by Claude from hand-annotated chart PNGs.
- `memory/` — working memory files describing the workflow, the 2025–2026 baseline
  analysis (726 trades, 32.9% win rate), and goals.

Finish line: 100 rows, then per-concept win rates get computed.
